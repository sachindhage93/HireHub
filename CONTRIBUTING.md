# Contributing to HireHub

Thank you for considering a contribution.

1. Fork the repository and create a feature branch.
2. Create and activate a virtual environment.
3. Install dependencies with `python -m pip install -r requirements.txt`.
4. Make a focused change and keep existing role checks and ownership rules intact.
5. Run `python manage.py check` and the relevant tests.
6. Open a pull request with a clear summary and testing notes.

Never commit `.env`, `db.sqlite3`, uploaded resumes, profile photos, company logos, passwords or secret keys.
